# Helper notes (Matt, 2026-11-02: "It needs to take notes too so it's not starting from scratch every time it compresses its memory.
# It's been working for you so it should work for them too.")

Every helper keeps its own notes file here, `reference/notes/<helper-name>.md`, the way the lead keeps STATUS.md. Memory compression
then loses nothing that matters, and nobody is retired or rotated for having a long memory.

**Rules:**
- Create it in your first commit. Read it at start and right after every memory compression (the start-up print reminds you).
- Update it at every report and every decision: the job and its R-numbers, what is done (with proof: commit, file, shot), what is in
  flight, decisions from the lead or Matt (dated, his words), what you were told to redo and why, your own pitfalls and how you avoid them.
- Short and current beats long: rewrite stale lines, don't pile on. Times from `TZ=America/New_York date`.
- Commit and push it with your work, so it survives the container too.
