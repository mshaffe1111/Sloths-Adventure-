# World fit (Matt, 11-11: "determine where they work the best... some may work in multiple worlds"; "universal for all art going forward")
Each cut piece lists every world it fits, best first, with a one-line reason (material and mood; STORY-KEEPER's ten worlds), and
says where it fills a gap from reference/art/KIT-AUDIT.md. `<batch>_fit.py` holds the tags; `apply.py <batch>_fit <cut folder>` writes
them into that batch's catalog.csv (`world`, `world_why`) and CATALOG.md (the per-piece table, counts, and a "By world" section).
