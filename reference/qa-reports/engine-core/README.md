# engine-core: live World 1 pits drawn as on main

w1Pits.ts paints only drops a builder marks (`pit: 'drop'`); on engine-core only the mixer's 1-1 and 1-5 mark any. These stills show
live World 1 pits (layout 1, Normal, the same frame, upright and sideways) on main and on engine-core: main is on top (sideways) or on the
left (upright). Soft pits (1-3, 1-6, 1-9), 1-6's water gap and 1-8's chase hole draw the same; only animated pieces (snakes, rain) move.
A pixel count can't separate them: main shot twice differs by as many pixels (2,500-35,000) as main against engine-core.
Made with a dev build of each tree, served locally (scratch script, not kept).
