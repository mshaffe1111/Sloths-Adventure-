## Learned (for the next level builder; each with the check that would hold it)

   trap is a broken bot, not a fast level (W1C's 126.2 s was 112 s). Check: castBots in CI (gates.yml); the report's bot-commit column.

3. **A designed group (a trap and the animals it is laid for) is DATA (`Socket.group`), never a fight with the lay's gap numbers.** Check:
   variety.test (planted).
4. **A rule written for one animal is re-proved when a beat puts two together** (a lone sleeper's 10 px load offset dropped the stone on the
   pair's far coil). Check: a test per pair rule, planted (library13 test 5).
5. **Judge a painted strip at its wrap:** edge art meets itself (the orchid "ghost"). Check: none yet; a strip-edge gate is suggested.
