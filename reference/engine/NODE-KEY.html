The node key

Every stage is a line of short codes. Each code is one stretch of play: what it's for, what it's made of and how it moves. This key says exactly what the engine builds for each code and how it plays for Pokey, so nobody has to guess.

How to read one code

Pjob: practise
cmade of: climb
2move: double jump
^shape: rising
+a find on it
>tempo: hurry

Pc2^+> reads as: practise the double jump up a rising stair, with a treasure on it, at a quick pace. The capital letter always comes first. A fork is written F[high|low].

The key

What a node can ask, and what the lay does with it

Any element mixes with any other on one node, in any world whose kit has the pieces. Every element a code writes is laid, or the roll fails and names it: nothing a designer writes is dropped. Laid: the lay builds it from the ask, and the built roll is checked. Checked: the lay rolls it as before, and the roll fails by name when it is not there. Later: nothing in the engine lays it yet, so a code that writes it always fails by name.

Pgcontent g f c b r k w hLaid

the node's type is fixed in the deal; every section laid there is checked to be that type

Pscontent s v p t xLater

no emitter keyed by the letter in this tree: the roll fails by name

Pg2move 1 / 2Checked

2: a section there asks for the double; 1: none does. A miss fails by name

Pg^shape ^ _Laid

the node's shape and height dial are the ask; its sections' net rise is checked (^ ends higher, _ lower)

U^^shape ^^ @ *Later

V10: a stage must own the shape; the shaft, loop-back and hub have no lay here

P+find +Checked

a find (the seed perch) laid in the node, or the roll fails by name

P&creatures & / &&Checked

&: a creature laid in the node; &&: two or more. A miss fails by name

P>tempo < >Laid

the node's tempo dial (the flat stretch's walk) is the ask

:7rating :7Laid

the node's rating (its sections' difficulty pick) is the ask

:&snake*2threat :&kind*n!Laid

the node's enemy sockets take only its kinds, up to their counts; each kind's count is checked

:&snake*1zthreat asleep zChecked

asleep only where the world lays that kind asleep (tag 'sleeper'); awake only where it does not

:#hurthazard :#soft :#water :#hurt :#voidChecked

a fall of that kind lies in the node's span, or the roll fails by name

:#pods@beathazard on a clock :#kind@clockLater

named clocks are B14's pods (t-b14): the roll fails by name

:+seedreward :+findChecked

the find laid in the node is that one

:$8reward :$nChecked

the pickups laid in the node number exactly n

:t0.9beat :t0.9Later

no clock piece in this tree keeps a beat: the roll fails by name

:p5.5points :p5.5Later

the meter (tools/difficulty/score.ts) does not score a node inside the lay yet: the roll fails by name

What 1-1 is made of

Each 1-1 roll is dealt its content from this mix, give or take one stretch. No type goes over 40%, and the same type never runs twice in a row, except practising right after a teach.
