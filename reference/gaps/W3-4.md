# Worlds 3-4 gap list (measure only), 2026-10-28

Branch: ccr-0d59a91c-oy3imz merged into the helper worktree (c018221). Nothing changed, nothing committed.
Runs: `inspect.ts --worlds 2-4 --firsttimer` on seeds 1, 2, 3 (`/tmp/w34s{1,2,3}.json` / `.html`).
Sameness = cosine of weighted action 3-grams (analyze.ts `profile`/`cosine`) between the three rolls. The target is 0.65 or less (diversity 0.35+).
"Bot" = first-timer bot, 2 runs per setting per roll. "Lives" = lives lost per run. "Kid/adult" = the noisy bots' hardest-jump success.

**Bot weak spots, check these by hand:** tall climbs (3-4, 4-1, 4-3, 4-6 time out at 45-90%), water/river deaths (3-8, 4-4), the long glide (4-7),
puzzles and pushing (the bot never throws or pushes, so 4-8 and the boulder rooms loop), prowler fights (it can't clear 3-3/3-9's goal, so the
ring wall stays shut), and 4-1/4-9, where it found no route and went straight for the shrine (4-9's numbers are empty).

What is fixed in every stage on every roll: the section order (Start, Learn, Develop, Twist, Finish). Every Start is the same log + dip hop
(3-1..3-9, 4-2, 4-4, 4-5). Every Finish cycles its pieces in a fixed order (`n % k`) and ends with the same `homeRun`.
A roll only changes widths, gaps, counts (3 or 4), stone heights (shuffled), and a few 50/50 wind directions.
